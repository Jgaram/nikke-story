# 사이트 정리 점검표 (W13)

SESSIONS.md W13(팬 사이트답게 · 작업 흔적 빼기)이 쓰는 작업 목록이다. 2026-10-10 계획 세션이 화면(여섯 탭 · 리더 · 검색 · 팝업, 라이트 · 다크 · 390px)과
`site/` 소스 전체를 훑어 모았다. 문자열로 적었으니 `grep -n`으로 찾는다(줄 번호는 다른 세션이 고치면 밀린다). 끝난 줄은 지우고, W13이 다 끝나면 docs/history/로 옮긴다.
원칙 · 등급 색 판단은 SESSIONS.md W13 머리, 규칙은 docs/views.md "화면 문구는 간결하게".

## 구조 문제 (먼저)

- **범위(층) 필터는 없앴는데 흔적이 남았다** — `state.js`가 layers를 [1,2,3]으로 고정해 "범위 밖 N" 안내는 죽은 코드. 층 칩(핵심 · 넓게)은 아직 뜬다: 리더 스토리 머리 · 감상 순서 분류 카드.
  `LAYER_HELP` · `SCOPE.help`도 같은 세 말에 뜻이 다르다. → 층 표시 · 범위 안내를 모두 걷어낸다.
- **`fmt.plain` · 키 → 이름 바꾸기를 안 거치는 데이터 문장**이 있어 내부 키 · ID가 화면에 샌다 — 연대기 추정 이유(423건 가운데 81건: `1회독` · `char:200` · `(06_e #47-59)` · F/S/D ID),
  설정 오류 메모(7건 모두 `05_s #161` · `F994(ch23 크로우)`꼴), 사전 대상 설명(`(R64 event_ce006에서 더함)` · `sub:고스트`), 연결 탭 연작 메모(28건 가운데 25건이 `liarsend` · `fullfoolday`꼴 키).
  → 화면에 내는 자유 문장은 모두 한 함수를 거치게 하고, 못 바꾸는 건 내지 않는다.
- **감상 순서 분류 카드의 "분류가 바뀐 기록 · 검토 기록"** — `B0b-2 2026-10-04 확정 — B0b-2 자체 검토 — 판정 입력(…)` · `그 전: 등급 독립 · 근거 J35`처럼 작업 로그가 그대로 뜬다. 가장 심한 곳. → 화면에서 뺀다.
- **"사전에서 보기"가 세계 탭이 아니라 리더를 연다**(떡밥 · 인물 탭) — 이름과 동작이 어긋난다.

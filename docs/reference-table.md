## 시트는 참고자료다 (반드시 지킬 것)

`data/raw/imported/story-relations-sheet.csv`(스토리 연관성 시트)는 **참고자료일 뿐이다.**
이 프로젝트의 분석(스토리 관계 · 중요도 · 선행 · 분류)은 원문과 게임 데이터에서 **독립적으로** 한다. 사용자가 정한 방향이다.

- 시트 값(유형 분류 · ★중요도 · 추천 선행 · 접근성 · 출시일)을 분석의 입력이나 정답으로 쓰지 않는다.
  분석 결과가 나온 뒤 참고로 비교해 볼 수는 있다.
- **중요도 판정 세션(X3f · N3 다시 판정)은 시트를 열지 않는다**(사용자, 2026-10-09 — 매우 중요): `data/raw/imported/` · `stories`의 `sheet_*` 칼럼 · `sheet_rows` · `--sheet`.
  다시 볼 단위를 시트와 어긋난 것으로 고르지 않는다. 견주는 일은 판정을 다 확정한 뒤(X3e)에만.
- 시트와 데이터가 다르면 데이터를 따른다. 시트 쪽 오류를 판단해 달라거나 고쳐 달라고 하지 않는다.
- DB에는 비교용으로 연결만 해 둔다: `sheet_rows`, `stories`의 시트 칼럼, `edges.origin = 'sheet'`, `sheet:` 노드.
  `read.mjs`는 시트 값을 보여 주지 않고, `query.mjs links`는 `--sheet`를 줄 때만 시트 엣지를 보여 준다.
- 예외 하나: 이벤트 표시명은 게임 데이터에 없어 시트 제목을 라벨로만 빌려 쓴다. 키는 게임 ID(`event_…`)다.

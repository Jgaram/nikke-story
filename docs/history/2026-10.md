원칙 (규칙은 docs/views.md "화면 문구는 간결하게"):
1. **첫 줄은 팬의 질문, 작업 흔적은 뺀다** — 근거 추적은 링크로만 남긴다(누르면 장면, URL · `sel`의 ID는 그대로). 당연한 것은 쓰지 않고 예외만 쓴다(직접 말함 ✗ → 이름만 나옴 ○).
2. **색은 한 뜻 — 등급만.** 종류는 글자(회색) · 모양. 종류 색은 종류가 축인 그림(인물 등장 · 연대기)에만.
3. **얼굴로 알아보게** — 초상 · 소속 마크를 정보 앞에. 게임 UI 톤(어두운 머리 바 · 카드 · 굵은 CH 표기), 한글 웹 글꼴, 줄거리 줄 길이 · 줄 간격.

등급 색 판단(Claude — 사용자가 화면을 보고 조율): **칠하되 한 종류만.** 감상 순서 기본 화면(필수 · 준필수 · 추천)에서 준필수 = 줄 왼쪽 굵은 띠 + 연한 바탕(시트의 칠하기),
추천 = 같은 계열 얇은 띠, 참고 · 독립 = 띠 없이 제목 회색(켜야 보인다), 메인 · 필수 = 지금처럼 구획 줄. 등급 이름은 띠 색 작은 글자로 남긴다(색만으로 가르지 않게).
명도 단계(지금 파랑 4단)가 아니라 색상으로 가른다. 기본 화면에서 칠하는 줄은 준필수뿐이라 번잡하지 않다 — 지금은 등급이 같은 파랑이고 종류 칩이 더 진해 우선순위가 거꾸로다.

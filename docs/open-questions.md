# 나중에 확인할 것

사용자에게 물어야 하지만 작업을 멈추지 않으려고 미뤄 둔 질문(주로 관리자가 연, 사용자가 지켜보지 않는 세션에서 — docs/operations.md "관리자").
질문마다 **잠정으로 정한 값**으로 일단 진행하고, 답을 받으면 그 값을 쓴 곳을 고친다.

- 여기 올리는 것은 **범위와, 원문 · 데이터로 알 수 없는 것**뿐이다(CLAUDE.md "일하는 법"). 작업 방식 · 원문 해석은 Claude가 정하고 근거를 남긴다.
- 상태: `[ ]` 답 기다림 · `[x]` 답 받아 반영함(답 · 반영 커밋) · `[-]` 없던 일로 함(사유).
- 번호는 항목 이름으로 `Q-W9a-1`처럼 붙이고 바꾸지 않는다. 칸: 질문 · 잠정(지금 쓴 값) · 근거(씬 ID · 줄 번호, 파일) · 영향(답이 다르면 고칠 곳).
- 지난 질문(A1 · A2 · A3 · R01, 모두 닫힘)은 [docs/history/open-questions.md](history/open-questions.md).

# 피드백 기록

지시 세션(docs/operations.md)에서 사용자가 준 피드백과 처리 결과. **끝에 덧붙이기만 한다**(여러 세션이 같이 써도 충돌이 적다).
규칙 · 결정이 바뀌면 그 주제 문서(docs/*.md · CLAUDE.md)를 먼저 고치고 여기에는 "→ 어디 반영"만 적는다 — 이 파일은 지금 맞는 규칙을 찾는 곳이 아니다.
한 세션을 넘는 일이 나오면 SESSIONS.md "할 일"에 항목으로 넣고 여기에 그 항목 이름을 적는다.

형식 — 한 건에 2–4줄:

```
## 2026-10-11 인물 탭 — 변화 줄이 작중 순서와 어긋남
- 요청: (사용자 말을 짧게)
- 원인 · 고친 것: … (커밋 abc1234)
- 반영: docs/views.md "5. 인물별 집계" · 남은 일: SESSIONS.md W12
```

## 2026-10-10 여기까지 읽음 팝업 · 감상 순서는 전부
- 요청: 상단 "여기까지 읽음"(슬라이더 · 첫 방문 드롭다운 바)을 상단을 누르면 언제든 뜨는 팝업으로. 감상 순서 탭은 읽은 곳과 관계없이 전부 — 안 본 사람의 순서 안내가 되게.
- 정한 것(사용자 선택): 팝업 = 메인 챕터 단추 격자 + 세밀 슬라이더 + 전부 보기(첫 방문이면 저절로 뜸 · "나중에"). 감상 순서는 목록 · 지도 전부(최종 등급) + "여기까지 읽음" 구분 줄, 분류 카드만 스포일러를 접어 가림.
- 반영: docs/views.md "상단 바 · 범위 · 여기까지 읽음 팝업" · 컷오프 규칙 · 감상 순서 표 줄, site/app.js · site/tabs/order.js

## 2026-10-10 메인은 순서대로, 본편 이벤트 · 사이드는 골라서
- 요청: 메인은 다들 순서대로 보니 팝업 단추를 줄이고, 본편 이벤트 · 사이드는 순서 없이 · 건너뛰며 보기도 하니(뉴비) 본 것만 고르게. 기록이 그걸 감당하는지 먼저 확인.
- 확인: 기록은 씬마다 드러냄만 적고 단계는 읽는 순서로 계산하게 되어 있다(결정 #8) — reveals.csv에 드러난 단위가 다 있다. 11편에서 처음 밝혀진 380건 중 메인이 다시 밝힌 것 17건.
  게임에서 이벤트 · 사이드는 메인 진행과 관계없이 볼 수 있다(사용자).
- 정한 것: 팝업 = 메인 슬라이더 + 이전 · 다음 챕터, 본편 이벤트 · 사이드 11편 체크. 여섯 탭 · 리더 · 검색이 단위 기준으로 가린다. 그 밖 메인 밖 스토리는 메인 위치를 따른다.
- 반영: docs/views.md 컷오프 규칙 · "여기까지 읽음 팝업", site/lib/state.js 머리말

## 2026-10-10 등급 화면 말 — 본편 → 필수, 엘리베이터 → 돌발
- 요청: "본편"을 "필수"로 바꾸고 나머지 등급 이름도 맞춰서. 엘리베이터는 정식 분류(돌발 스토리) 이름으로.
- 정한 것: 필수(척추) · 준필수(키 필수) · 추천 · 참고 · 독립, 선행 칸 필수 → 꼭(같은 날 되돌림 — 선행 줄은 머리말 뒤라 헷갈리지 않는다, 사용자). 종류 엘리베이터 → 돌발. 키 · 데이터 · 판정 문서는 그대로.
- 반영: docs/views.md "표기 · 색" 아래 "화면 말 바꿈", site/lib/format.js(GRADE · PRE_LABEL · KIND · plain)

## 2026-10-10 등급 기준 — 감정의 무게
- 요청: 등급(필수 · 준필수 · 추천)이 내용 이해로만 재진다. 감정적인 면 때문에 필독으로 꼽히는 스토리가 있고, 가장 주요한 인물을 다루면 더 그렇다. AI가 감동을 판단할 수 있나?
- 확인: 감동의 질(연출 · 취향 · 평판)은 기록에도 원문에도 없다. "누구의 어떤 결정적 순간이 여기에만 있나"는 기록(인물 변화 D 2,160건 · 마무리 기록 O · 1회독 사건)으로 잴 수 있어 원문을 다시 읽지 않아도 된다.
- 정한 것(사용자): 감정의 무게를 등급에 넣는다(따로 표시하는 안은 기각). 개별 스토리 판정은 사용자 의견을 듣지 않은 세션 · 에이전트가 한다 — 기준 · 테스트에 특정 스토리를 기대로 넣지 않는다.
- 반영: docs/importance.md 9절 · 남은 일: SESSIONS.md X3g-1 · X3g-2 · X3g-3

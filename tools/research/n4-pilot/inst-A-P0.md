# Pilot A · 조건 P0 — 지금의 1회독 방식 (기준선)

이 단위를 **지금 쓰는 1회독 규칙**대로 읽고 기록한다. 인계는 "열린 의문 전부"(questions-all.md) 하나다.

## 먼저 읽을 것
1. `questions-all.md` — 이 단위 앞까지 던져졌고 아직 안 풀렸거나 일부만 풀린 의문 전부(앞 세션들의 기록). 원문을 읽다가 이 가운데 풀리는 것이 있으면 회수로 적는다.
2. `text.md` — 이 단위 원문(read.mjs 출력 그대로).

## 무엇을 남기나 (1회독 — 줄거리 층)
드러난 것만 남긴다. 행동 · 묘사로 흘린 복선 · 암시는 적지 않는다.
- **단위 요약** `summary` — 다음 세션이 원문 대신 읽는 줄거리. 300–1,000자.
- **밝혀진 사실** `facts` — 독자가 새로 알게 된 사실. 한 문장. `id`는 `N1`, `N2` …(이 세션 번호). `about`에 다루는 대상 이름(인물 · 장소 · 조직 · 개념)을 적는다.
- **던져진 의문** `questions` — 이야기가 독자에게 던진 물음, 물음표로 끝나는 한 문장. `id`는 `NQ1` ….
- **회수** `payoffs` — 앞 의문(questions-all.md의 `Q<n>`)이 **드러내 놓고 풀린 곳**. `{ "question": "Q10", "answer": "N3", "degree": "전부"|"일부", "evidence", "reason", "confidence" }`. 원문이 그 의문과 직접 이어 주지 않으면 적지 않는다(추측으로 잇지 않는다).
- **시점** `times` — 이 단위가 언제인지 실마리가 있으면 한 줄(없으면 빈 배열).
- `slips` — 설정 오류로 보이는 것 한 줄씩(없으면 빈 배열).

확실 = 원문이 직접 말하거나 보여 줌. 추정 = 인물의 추측 · 기록자가 이은 연결.

## 출력
`{OUT}` 에 JSON 하나:
```json
{ "unit": "…", "condition": "P0", "summary": "…", "facts": [ { "id": "N1", "text": "…", "about": ["…"], "evidence": [{ "scene": "…", "lines": ["12-14"] }], "reason": "…", "confidence": "확실" } ],
  "questions": [ … ], "payoffs": [ … ], "times": [ … ], "slips": [], "memo": "읽기 메모" }
```

# Pilot C — 기록만으로 하는 회수 대조 (가설 ①)

1회독이 "원문이 직접 이어 주는 회수"만 적어 열린 의문이 많이 남았다. 가설: **열린 의문마다 그 뒤 같은 대상 · 같은 낱말의 사실을 보여 주고 다시 판정하면** 놓친 회수를 찾을 수 있다. 네 몫은 그 판정이다 — 원문을 열지 않고 **기록 문장만으로**.

## 입력
`input.md` — 의문마다: 문장 · 제기 자리 · 상태(열림 · 일부) · 줄기 · 대상 · 1회독 이유, 그리고 **뒤 사실** 후보 목록(◆ = 대상이 겹침, 괄호 = 겹친 낱말). 후보는 기계가 고른 것이라 답이 목록 밖에 있거나 아예 없을 수 있다.

## 판정 기준 (새)
- 뒤 사실이 그 의문을 **직접 잇지 않아도**, 대상 · 상황 · 시점이 맞아 독자가 "그게 그거였구나" 할 수 있으면 **회수**다. 확신도: 문장이 직접 답하면 `확실`, 추론이 들면 `추정`.
- 의문에 물음이 둘 이상이면 **물음을 쪼개** 어느 물음이 어느 사실로 풀렸는지 적는다. 핵심 물음(앞쪽 · 제목 격)이 풀렸으면 `전부`, 곁 물음만이면 `일부`. 남는 물음은 문장째.
- 후보가 답이 아니라 **새 단서**(의문을 키우거나 좁힘)면 `단서`.
- 답이 없으면 `없음` — 왜 후보들이 답이 아닌지 한 줄.
- 입력의 의문 가운데 **같은 수수께끼**로 보이는 쌍이 있으면 끝에 `same_as`로 적는다.
- 원문을 봐야 정해진다 싶으면 `보류`로 두고 어느 씬을 보면 되는지 적는다(열지 않는다).

## 출력
`{OUT}` 에 JSON:
```json
{ "judgments": [ { "question": "Q10", "decision": "회수 전부"|"회수 일부"|"단서"|"없음"|"보류",
    "answers": [ { "fact": "F242", "covers": "어느 물음을 푸나 (한 구절)", "confidence": "확실"|"추정" } ],
    "split": ["물음 1 …?", "물음 2 …?"], "remaining": "남는 물음 (없으면 null)", "reason": "두 문장 안쪽", "check_scene": "보류면 볼 씬" } ],
  "same_as": [ ["Q20", "Q63", "이유"] ],
  "memo": "판정하며 느낀 것 — 후보 목록의 쓸모 · 기준의 빈틈 · 품" }
```

# 공개 사이트 (CLAUDE.md "저작물 취급"의 사이트 몫)

- 공개 사이트에는 **대사 본문 전문을 싣지 않는다.** 근거는 씬 ID · 줄 번호, 인용은 40자 미만.
- 게임 이미지는 실어도 된다(시프트업이 요청하면 내린다).
- 스토리별 줄거리는 **확정한 공개 개요**(`annotations/synopsis/`)만 싣는다.
- 자세한 것은 docs/views.md "공개 규칙", 화면 · 모듈 규약은 docs/views.md "파일 배치 · 모듈 규약 · 실행법".
- 안 본 스토리가 새지 않게 — 점검 도구 `tools/site/spoiler-check.mjs`(docs/views.md).
